Trained on 5,000 labeled URLs (2,500 phishing / 2,500 legitimate) using 16 lexical and structural features computed directly from the URL string — length, entropy, suspicious keywords, hyphen/digit counts, TLD reputation, and more. Random Forest classifier, evaluated on a held-out 20% test split. Phishing examples follow well-documented real-world construction patterns (brand impersonation, IP hosts, URL shorteners, homograph-style subdomains).

Educational project — not a substitute for enterprise threat intelligence. Always verify suspicious links independently.
